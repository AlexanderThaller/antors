= API overview
:navtitle: Overview

The `api` module exists so the navigation has three separate lists, each with
its own title.

== Endpoints

[cols="1,1,3", options="header"]
|===
| Method | Path | Meaning

| `GET` | `/components` | Every component in the site.
| `GET` | `/components/\{name}` | One component.
| `GET` | `/search?q=` | The search index.
|===

See xref:errors.adoc[] for what can go wrong.
