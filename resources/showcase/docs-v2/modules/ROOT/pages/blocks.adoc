== Admonitions

NOTE: A note, in its one-line form.

TIP: A tip.

IMPORTANT: Something important.

CAUTION: Proceed carefully.

WARNING: Do not proceed.

[NOTE]
====
A note in block form, so it can hold more than a paragraph.

* Including a list.
* And another item.
====

[IMPORTANT]
.A titled admonition
====
The title sits above the icon column.
====

== Sidebar

.A sidebar with a title
****
A sidebar holds an aside that would break the flow of the main text.

It can contain other blocks:

TIP: Even an admonition.
****
