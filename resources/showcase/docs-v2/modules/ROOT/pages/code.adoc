== Callouts

[source,rust]
----
use std::fs;

fn read(path: &str) -> std::io::Result<String> { // <1>
    fs::read_to_string(path) // <2>
}
----
<1> The signature returns a `Result`, so the caller decides what a failure means.
<2> The body is one call; everything else is the type.

== Included from an example

The whole file:

[source,rust]
----
include::example$server.rs[]
----

Only the tagged region:

[source,rust]
----
include::example$server.rs[tag=main]
----

Two tags at once:

[source,yaml]
----
include::example$playbook.yml[tags=site;content]
----

A range of lines:

[source,rust]
----
include::example$server.rs[lines=1..3]
----

An indented region, re-indented:

[source,rust,indent=0]
----
include::example$server.rs[tag=imports]
----
