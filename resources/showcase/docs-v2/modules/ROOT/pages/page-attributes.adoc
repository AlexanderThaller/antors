Attributes whose name starts with `page-` are *page attributes*: they are
carried into the UI model rather than used by the converter, so a template can
read them.

== The ones the default UI reads

`page-aliases`:: Other resource IDs that redirect here.
`page-role`:: Extra classes on the `article` element. This page sets `-toc`.
`page-toclevels`:: How deep the right-hand outline goes.
`page-partial`:: Keeps the page's source for other versions to reuse.
`page-edit-url`:: Overrides the computed "Edit this page" link.

== The ones a custom template might read

This page sets `page-tags` to `{page-tags}`, which no default template shows.
A custom UI can put it in the toolbar.

== Document attributes that are not page attributes

`description` and `keywords` become `<meta>` tags. `navtitle` changes what the
navigation shows without changing the heading.
